# Critérios para tornar público

- [ ] Procedência de todo código/material integrado demonstrada e permissões documentadas.
- [ ] Licença pública definida para o trabalho de titularidade comprovada.
- [ ] Licenças e avisos de terceiros preservados e SBOM gerado.
- [ ] CI, testes web/backend, análise de segurança e lint aprovados.
- [ ] Nenhum segredo, arquivo de evidência real ou dado pessoal indevido no histórico Git.
- [ ] Controles de upload, autenticação, SSRF, permissões e quotas validados nos módulos correspondentes.
- [ ] Documentação e afirmações de funcionalidades refletem testes realizados.
- [ ] Decisão explícita do proprietário do projeto para alterar visibilidade do repositório.
