# Procedência e titularidade — pendente

## Situação da base entregue

O ZIP original `Protocolo-OSINT.zip` contém uma página `License.html` que informa © 2024 Rodrigo Roldan, com restrições de redistribuição e uso comercial. O arquivo `MUDANCAS.md` menciona uma pendência de atribuição da base IntelTechniques / Michael Bazzell. Esses dois dados **não bastam** para concluir quem detém os direitos de todas as partes.

## Processo antes de integrar/publicar

1. Inventariar cada arquivo-fonte legado e identificar histórico comprovável de criação, permissões e cópias.
2. Distinguir conceitos/metodologias gerais de elementos protegidos (texto, código, imagens, layouts, materiais copiados).
3. Confirmar a cadeia de titularidade e obter as permissões necessárias.
4. Preservar avisos de copyright/licença exigidos por dependências usadas.
5. Registrar origem, versão, licença, modificações, redistribuição e possíveis obrigações copyleft em `THIRD_PARTY_NOTICES.md`.
6. Publicar apenas após revisão de procedência e licença escolhida para o código efetivamente próprio.

O produto pode ter marca e identidade próprias, sem alegar autoria exclusiva de bibliotecas de terceiros. Referências a projetos externos não precisam dominar marketing, mas avisos de licença não podem ser falsificados ou removidos quando exigidos.
